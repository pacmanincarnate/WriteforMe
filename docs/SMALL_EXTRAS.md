# Small extras

Four small additions from the Prosperos list.

## Markdown export

The **MD** button at the bottom of the sidebar saves the manuscript as one `.md` file: the title and author, a heading for each act (when the story has more than one) and each sequence, and the written scenes in reading order with `* * *` between them. A sequence with nothing written is left out. Scene text is kept exactly as written.

## PDF, through the print window

The **PDF** button lays the manuscript out for print (a title page, each sequence on a new page, indented paragraphs) and opens the print window. Choose **Save as PDF** there to make the file. No PDF library is added to the app, and the page size, margins and page numbers are the ones the print window offers.

## Relationship web as Mermaid

On the **Relationships** page, **Export Mermaid** saves the web as a `.mmd` flowchart: a node for each character and a labelled arrow for each relationship. The same bond recorded in both directions becomes one two-way arrow. The file can be pasted into any Markdown page that draws Mermaid (GitHub, Obsidian, most wikis).

## OpenDyslexic in the reader

The reader's **Typeface** list has **OpenDyslexic**, a typeface made to be easier to read with dyslexia. It ships with the app (SIL Open Font License, from the `@fontsource/opendyslexic` package) and works offline. Its files are only loaded when it is picked.

## Not done from the same list item

- **Believability rules for characters.** The Prosperos rules are written for everyday companion characters (ordinary jobs, no chosen ones, ages 24 to 60). Adding them to the cast prompts would change what every story's cast looks like, and that needs a run on a real model to judge.
- **Hardware check and operating system key store for the Windows app.** Both live in the desktop shell and need a Windows machine to try.
