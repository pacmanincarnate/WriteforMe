Detailed Narrative Generation Pipeline & Cascading Rollbacks
Narrative Generation Flow
Phase 1: Story Conception & Worldbuilding
Step 1 Tier 0.1
Conceptual Development Agent
large-model Generates core genre classification, world bible status quo, and initial character briefs.
Inputs: User raw outline text, style guides, atmosphere/tone goals, imported world lore contexts.
Gate: Successful YAML/XML structure parse
Step 2 Tier 0.2
Character Developer (Interviews)
large-model (Sequential Loop) Interviews each generated character brief in first-person to extract deep dossiers and voice guides.
Inputs: World bible context, active character briefs (id, name, role, core flaw, core desire).
Gate: All dossiers successfully generated
Step 3 Tier 1.1
Story Arc Agent
large-model Establishes inciting incidents, core narrative threads (A/B plots), character arc parameters, and twists.
Inputs: World bible details, style guides, cast voice files, core character desires and emotional flaws.
Gate: Passes XML/YAML parse checks
Step 4 Tier 1.2
Story Arc Reviewer
small-model Validates story values, themes, and emotional twist pacing milestones. Outputs status PASS or FAIL.
Inputs: Raw concept outlines, world bible status quo, newly generated story arc parameters plan.
Gate: Reviewer status == 'PASS' (Loops back if FAIL)
Phase 2: Structural Outlining
Step 5 Tier 2.1
Act Planner (Act Agent)
small-model escalates to large-model Generates structural Acts with titles, mandates, world developments, and story knots. Up to 3 attempts.
Inputs: Core narrative concept, theme milestones guidelines, character list, twists, and structural thresholds.
Gate: Passes Programmatic validation (>= 3 Acts, details length)
Step 6 Tier 2.2
Act Reviewer
small-model Checks Act mandates for logical cohesion, milestones, and theme matches. Outputs status PASS or FAIL.
Inputs: Generated Act outlines array, major twists list, inciting incidents, theme milestones.
Gate: Reviewer status == 'PASS' (Loops back if FAIL)
Step 7 Tier 3.1
Chapter Planner (Chapter Agent)
small-model escalates to large-model (Loop for each Act) Generates chapter objects detailing titles, objectives, and pacing milestones. Up to 3 attempts.
Inputs: Detailed Act mandates, cast dossiers, story/style guidelines, and active target Act parameters.
Gate: Passes Programmatic validation (>= 5 Chapters)
Step 8 Tier 3.2
Chapter Reviewer
small-model Ensures chapters follow pacing guidelines and have logical flow. Outputs PASS or FAIL.
Inputs: Newly generated chapter plans structure list, parent Act objectives, theme guidelines.
Gate: Reviewer status == 'PASS' (Rolls back if 3 failures)
Step 9 Tier 4.1
Scene Planner (Scene Agent)
small-model escalates to large-model (Loop for each Chapter) Builds scene rosters: settings, casts, dominant mode, and value/relationship shifts.
Inputs: Act/Chapter details schema, cast dossiers list, world bible rules, active Chapter objectives.
Gate: Passes Programmatic validation (>= scenes range limit)
Step 10 Tier 4.2
Scene Reviewer
small-model Ensures scenes feature appropriate character presence and value shifts. Outputs PASS or FAIL.
Inputs: Newly generated scene structure roster, parent chapter objectives, active character list.
Gate: Reviewer status == 'PASS' (Rolls back if 3 failures)
Phase 3: Choreography & Writing (The Autopilot Beat Loop)
Step 11 Tier 5.1
Beat Planner (Beat Agent)
small-model escalates to large-model (Loop for each Scene) Lays out choreographic beats: start positions, turning pivots, reactions, and exit states.
Inputs: Scene directives, cast dossiers, relationship ledger, style guides, preceding beat plans.
Gate: Passes Programmatic validation (>= beats range limit)
Step 12 Tier 5.2
Beat Reviewer
small-model Validates beat structure depth, physical posture continuity, and character actions. Outputs PASS or FAIL.
Inputs: Newly generated beats choreography plan, parent scene parameters, cast voice dossiers.
Gate: Reviewer status == 'PASS' (Rolls back if 3 failures)
Step 13 RAG Preprocess
Query Expansion
small-model Extracts implicit keywords, relationships, and locations from raw action parameters to optimize context retrieval.
Inputs: Raw choreography beat action description text, active cast list, scene location.
Gate: Preprocessed terms returned
Step 14 Tier 5.3
Writing Agent (Prose Gen)
small-model Generates raw narrative prose text (400-600 words) from RAG contexts and choreography directives.
Inputs: Choreography beat instructions, preceding beat prose, cast cards, RAG lore details, style guides.
Gate: Passes prose length validation guidelines
Step 15 Validation
Continuity Reviewer
small-model Compares new prose against previous beat's prose, checking for logical inconsistencies, teleportation, or posture slips. Outputs PASS/FAIL.
Inputs: Preceding beat's prose text, newly generated prose draft, target choreography instructions.
Gate: Reviewer status == 'PASS' (Loops to Editor or Writer on FAIL)
PASS Path
Seamless transition. Moves on to word filtering checks.
FAIL Path
Consistency gaps detected. Routes to editor or rewrite loop.
Step 16 Recovery
Continuity Editor (Surgical Patch)
large-model Applies targeted search-and-replace edit blocks to rectify minor/major transitions without rewriting the entire beat.
Inputs: Preceding beat's prose, newly generated prose draft, reviewer's detailed critique checklist reasons.
Gate: Search-and-replace block applied successfully
Step 17 Sanity Check
Banned Words & Surgical Patch
Code Check & Surgical AI Checks for filter words / cliches. If >2 matches, runs a Surgical Editor to swap them with fresh prose contextually.
Inputs: Finalized prose text draft, global banned phrases/cliches blacklist parameters.
Gate: Banned phrases count <= 2 (or patch applies)
Step 18 Post-Process
Archivist (End of Scene)
large-model (JSON output) Runs at the end of a scene. Indexes new lore facts, updates cast goals, and records relationship changes into the World Bible database.
Inputs: Concatenated text of all beats in the scene, current cast profiles, lore database topics schema.
Gate: JSON output validates and parses successfully
